      <h2>⚙️ How I Work</h2>
    </th>
  </tr>
  <tr>
    <td valign="top">
      <strong>📦 Ship weekly.</strong> Every engagement produces something demoable in 7 days. No months-long architecture phases.<br/><br/>

    </td>

      <strong>🤖 Automate the 80%.</strong> Agents handle the repeatable work; humans (me) handle judgment, taste, and the parts customers feel.<br/><br/>
      <strong>🔪 Delete before optimize.</strong> The cheapest feature is the one you never build. I'll tell you what <em>not</em> to spend money on.
